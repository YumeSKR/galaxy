# 星空 · 银河系

🔗 **在线预览**：[yumeskr.github.io/galaxy](https://yumeskr.github.io/galaxy/)

一个完全用**手写 SVG** 实现的交互式银河场景 —— 没有 Canvas、没有第三方库、没有构建步骤，双击 HTML 文件即可运行。

约 980 颗星分成 4 层深度，鼠标移动时按不同系数产生视差；银河盘由多层椭圆与径向渐变叠出，尘埃带沿椭圆轨道持续环绕银心。

## 交互

| 操作 | 行为 |
|---|---|
| 移动鼠标 | 8 层视差 + 光标柔光跟随 + 星尘尾迹 |
| 点击星空 | 在落点种一颗星（双圈扩散光环 + 星核持续闪烁，永久保留并计数） |
| `F` | 召唤流星雨（同一辐射点散开的扇面，模拟真实流星雨） |
| `空格` | 定格星空（暂停 CSS 动画与 SMIL 动画） |
| `C` | 切换色调：深空 / 极光 / 玫瑰 |
| `R` | 清除种下的星 |
| `H` | 隐藏界面 |

## 银河的构造

自下而上五层叠加，全部放在一个 `translate(800 450) rotate(-20)` 的组里：

1. **星系晕** — `rx940 ry490` + 大半径模糊，只提供底噪
2. **主盘** — `rx660 ry310` + 中等模糊，带状实感全靠这层
3. **银心** — 偏置在 `cx-130`，暖黄双层，带呼吸动画
4. **尘埃暗环** — 5 条与主盘**同构**的椭圆环（长短轴比均 ≈ 2:1），最外三环逐级降低不透明度，让暗纹向外平滑融进盘缘辉光
5. **环绕尘埃团块** — 8 个暗色团块沿 3 条椭圆轨道用 SMIL `<animateMotion>` + `<mpath>` 绕银心运行，内圈 38s、中圈 62s、外圈 88s（内快外慢）

> 尘埃带的椭圆必须与所在盘的椭圆**同构**。早期版本用了 `rx580 / ry26`（≈22:1）的极扁椭圆，在眼里已退化成"直线条"，看起来就像椭圆里画了几道直线。

## 开场

进入页面时，银心位置先亮起一点闪光，星光通过 `<mask>` 里一个 SMIL 动画的 `<circle>`（`r` 从 0 扩散到 1500）自内向外铺满全屏，随后界面淡入。遮罩扩散结束后立即移除，避免整个场景持续走离屏合成。

## 一些实现取舍

- **`feGaussianBlur` 会摊薄椭圆能量** —— 模糊越大元素越糊越暗。单靠加大 blur 会把带状结构糊成一团云，正确解法是**多层叠加**：大模糊层做弥漫辉光，中等模糊层保留结构。
- **移动的元素不要挂滤镜** —— 尘埃团块改用 5 段 `radialGradient` 模拟高斯衰减，去掉滤镜后帧率从 17.7 升到 35.9fps。
- **逐帧写入的位置不能再挂 CSS `transition`** —— 光标柔光原先在每个 `pointermove` 里写 `transform`，同时 CSS 上有 `transition:transform .5s`，导致过渡被不断重启、永远追不上指针。改由 JS 指数平滑推进，CSS 只管淡入淡出。
- **`userSpaceOnUse` 的 filter region 必须罩住最大的子元素** —— 外环曾因 y 范围超出 region 被硬裁出斜切边；百分比 region 会裁细长元素，绝对坐标 region 则容易在改尺寸后忘了同步。
- **CSS `transform` 会覆盖 SVG 的 `transform` 属性** —— 视差位移放外层 `<g>`（CSS），定位旋转放内层 `<g>`（属性），分两层互不干扰。
- **暂停要管两套动画** —— CSS 动画靠 `body.paused`，SMIL 要单独调 `svg.pauseAnimations()`。

## 运行

无需安装任何依赖，直接用浏览器打开即可：

```bash
open index.html      # macOS
start index.html     # Windows
xdg-open index.html  # Linux
```

建议使用 Chromium 内核浏览器（Edge / Chrome），以获得完整的 SVG 滤镜与 SMIL 支持。

> 背景音乐需要用户手势后才能播放（浏览器自动播放策略），首次点击或按键时淡入。
